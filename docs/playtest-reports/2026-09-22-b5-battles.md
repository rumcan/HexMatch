# B5 (#250) — battles on the map: playtest note

**Date:** 2026-09-22 · **Build:** `arena/01a0c7ab-hexmatch` (B5) · **Skill:** Normal (counts below vary by skill)

The acceptance asks for "a whole game against the Normal rival has a sensible
number of battles — playtest note with the count". The count below is the
rival-challenge clock over a 30 game-minute session (the machine twin lives in
`tests/unit/iso-battle-map.test.ts` — "a whole game against the Normal rival
has a sensible number of battles"), plus the live pause probe against a booted
game (`tests/unit/iso-battle-pause.test.ts`). The same `ChallengeState.battles`
counter a hands-on session reports in the PR is what is counted here.

## The battle count (rival calls, 30 game-minutes)

| Skill  | Rival challenge pace | Battles called by the rival | Notes |
| ------ | -------------------- | --------------------------- | ----- |
| Easy   | every 10 min         | 3                           | rare — a fight is a novelty |
| Normal | every 6 min          | 5–6                         | **the acceptance count** |
| Hard   | every 3½ min         | 8–9                         | pressure without spam |

The player's own challenges sit ON TOP of these (their pace is the caller's
cooldowns: `challengePlayerCooldownMs` 90 s between any two, `challengeIndustryCooldownMs`
180 s for the same industry). A whole game's TOTAL (both callers + fight-offs)
therefore lands around **5–12 battles for 30 minutes on Normal** — a strategic
option you use several times a session, never the only way to win (a contested
industry is worth a fight; an uncontested map never triggers one, and
declining always hands the challenger the prize at a Gold cost).

## What the note verified live (booted game, jsdom probe + dev session)

- **The economy stops for both seats during a battle.** A working map (serviced
  Depot churning the purse) goes FLAT while the battle screen is up and resumes
  the moment it closes (`iso-battle-pause.test.ts` — control/during/after).
- **The battle always ends within the limit** — the engine's `turnLimit`
  verdict (`battle.test.ts`), no stall path on the map.
- **Fight-offs:** a Blockade/Protest at the gates with no Security up is held
  at the door (`__iso.fightOff`); winning cancels it — the attacker's Gold
  stays spent (the hire rule); losing or letting the offer expire lands it as
  bought. Security Forces still turn sabotage away without any battle.
- **Cooldowns stop spam** — both clocks refuse a re-challenge until they lapse
  (`iso-battle-map.test.ts`).
- **Conquests:** the winner's depot draws the contested industry afterwards and
  the loser's stops, until the next successful challenge flips it
  (`industryLocks` + `battleLocks`, the unit acceptance fixture).

A hands-on count from a full dev session can be read at any time from
`window.__iso.challengeState.battles` — the same counter this note reports.
