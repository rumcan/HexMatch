## Method, and its one caveat

The sandbox has **no browser**: `npx playwright install chromium` cannot reach
the CDN and `apt-get` cannot reach Debian, so `npm run test:e2e` cannot run
here. Two substitutes, both driving the **real** built app with no game code
mocked:

1. **A live dev server** (`npm run dev`, `?seed=1337`) so the human can click
   the same five steps in a real browser. Do this before closing any ticket.
2. **A headless harness** — jsdom (real DOM, real React, real event dispatch
   through the real listeners) backed by `@napi-rs/canvas` (real Skia
   Canvas2D, so the iso renderer genuinely rasterises and layers can be
   pixel-counted). Only what jsdom lacks is shimmed: canvas raster, PNG
   decode, layout boxes, pointer capture. Every click is a real
   `pointerdown`/`pointermove`/`pointerup` on the real overlay canvas, at
   coordinates derived from `window.__iso.tileScreenAt`; every build is the
   real drag path; every match is the real `board.trySwap`.

**Caveat:** jsdom has no CSS layout, so this run cannot catch *occlusion*
bugs — a HUD panel sitting on top of a tile and swallowing the click. The
e2e suite asserts that (`document.elementsFromPoint`); this run does not.
Everything else below is genuine end-to-end behaviour.

The game was played three times end to end; results were identical apart from
board randomness. 21 of 23 checks pass on every run.

## Step 1 — place factory → place harvester → connect them with road

**PASS**

```
clicking a tile places the Factory (and seeds the rival's)      phase=setup-harvester factories=2
clicking beside an industry places the Harvester and starts play phase=play harvesters=1
dragging road from harvester to factory lays track and scores it drag length=5 network tiles=5 vp.you=1
```

Setup phases advance correctly, the rival's factory is seeded, the 5-tile drag
lays 5 tiles, and the road connection awards 1 VP on commit.

## Step 2 — match gems; cargo rises, and only for connected industries

**PASS**

```
connecting the harvester makes its industry's cargo reachable   reach={"ore":0.8}
tokens spawn on the board for reachable cargo                   tokened gems=1
the 20s token clock keeps the board stocked with tokens         tokened gems=9
matching a tokened gem credits that cargo to the purse          ore 0 → 2
a token on an UNCONNECTED cargo is refused                      grain 0 → 0
```

Both halves of the J1 join hold. The gate is a real gate: a token planted by
hand on a cargo the network does not reach is refused at match time with the
"No route for X" toast, and the purse does not move.

## Step 3 — spend cargo to build more road/rail

**PASS**, with one balance defect.

```
building road past the free allowance debits stone   requested=20 laid=14, free 2→0, stone 12→0 (−12)
rail only lays tiles it can pay for                  free=0 ore=1 → new rail tiles=0
no purse value ever goes negative                    {"grain":0,"wood":0,"ore":1,"stone":0,"oil":0,"gold":0}
an ore mine connected by road makes ore reachable    reach={"ore":1.28}
ore reaches the purse by matching ore tokens         purse.ore=5
rail can be built with ore once the free allowance is gone  rail tiles 5→6, ore 5→1
rail laid over the road line upgrades the connection  rail tiles=5/5, vp 1 → 3
```

The cost model is sound end to end: the preview truncates at the last
affordable tile (a 20-tile drag with 2 free + 12 stone lays 14, not 20), the
commit charges exactly what the preview showed, no purse value can go
negative, ore income is gated on a connected ore mine, and the road→rail
upgrade correctly costs 4 ore and correctly lifts the connection to rail VP.

**Defect:** while free setup tiles remain, rail is free — see
[W9](../tickets/W9-free-setup-track-pays-for-rail.md).

## Step 4 — gold from combos reaches the purse

**PASS** — the W5 wire is connected.

```
a completed combo mints gold and it lands in the purse
  comboCount 0 → gold 0 → 0 → 1 (expected +0 then +1 total)
```

Two `registerCombo()` calls — exactly what `Board.settle()` does on a cascade —
mint one coin and the purse gains exactly 1 gold. The Black Market is therefore
reachable without owning a gold mine.

## Step 5 — the rival builds its own road and doesn't ride yours

**FAIL — the rival never builds.** See
[W8](../tickets/W8-rival-never-builds.md).

```
the rival builds its own track        FAIL rival-owned tiles=0 rival network=1 rival harvesters=0
the rival's network never crosses the player's  PASS shared tiles=0
the rival scores on its own connections         FAIL vp={"you":3,"ai":0}
```

Track ownership itself is fine — the two networks never overlap; there is
simply nothing of the rival's to overlap with. Eight injected AI turns produce
zero tiles, while the rival's factory has 25/25 industries and 671 tiles of
walkable ground in range. The rival is idle in ~25–32% of games on the seeds
swept (51/160 placements on seed 1337, 37/157 on seed 7).
